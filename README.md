## Getting started

#### 1. Create the virtual environment to store the dependencies you will install (it's good to avoid the global installation of dependencies)

```bash
python -m venv .venv
```

#### 2. Run the command to activate .venv enviroment

```bash
# Windows
.\.venv\Scripts\activate

# MacOS or Linux
source .venv/bin/activate
```

#### 3. Install the dependencies that are in requirements.txt

```bash
make install
```
